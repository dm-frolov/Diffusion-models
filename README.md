# Сравнение диффузионных моделей

Данный репозиторий содержит Jupyter Notebook с экспериментальным исследованием и сравнением различных подходов к генерации данных с помощью диффузионных моделей и родственных методов.

Код **«Сравнение диффузионных моделей»** был разработан в рамках дипломной работы, посвящённой исследованию диффузионных моделей и их альтернатив. Основная цель экспериментов — наглядно исследовать динамику генерации, сравнить различные методы переноса распределений и оценить качество получаемых результатов.

## Основные исследуемые методы

В работе рассматриваются три основных подхода:

1. **Диффузионная модель на основе VE-SDE**

   * используется Variance Exploding SDE;
   * для обучения применяется **Score Matching**;
   * нейронная сеть `ScoreNet` обучается восстанавливать score-функцию распределения;
   * генерация выполняется посредством обратной динамики SDE/ODE.

2. **Классический мост Шрёдингера**

   * используется для построения наиболее вероятной стохастической траектории между двумя распределениями;
   * оптимальное сопряжение распределений вычисляется с помощью алгоритма **Sinkhorn**;
   * полученная траектория моделируется как стохастический процесс.

3. **Нейронный мост Шрёдингера**

   * основан на подходе **Flow Matching**;
   * нейронная сеть `BridgeDriftNet` аппроксимирует поле скоростей;
   * пары начальных и конечных точек формируются с использованием оптимального сопряжения Sinkhorn;
   * генерация выполняется интегрированием соответствующего поля скоростей.

В ноутбуке эти три метода рассматриваются как разные способы построения динамики перехода между распределениями.

## Структура экспериментов

### 1. Подготовка окружения

В начале устанавливаются необходимые зависимости и импортируются основные библиотеки:

* **PyTorch** — построение и обучение нейронных сетей;
* **NumPy** — численные вычисления;
* **Pandas** — обработка результатов;
* **Matplotlib** — визуализация;
* **tqdm** — отображение прогресса обучения;
* **ipywidgets** — интерактивные элементы.

Также реализована возможность использования CPU или CUDA при наличии совместимой видеокарты.

Предусмотрена переключаемая светлая и тёмная тема визуализации.

### 2. Генерация тестовых распределений

Для экспериментов используются искусственно созданные двумерные распределения, позволяющие исследовать поведение моделей на данных различной сложности.

В частности, реализованы:

* гауссово распределение;
* смещённое гауссово распределение;
* смеси из 2 и 8 компонент;
* кольцевое распределение;
* `two moons`;
* шахматное распределение;
* пуассоновы оболочки;
* равномерное распределение;
* распределение с двойной потенциальной ямой;
* двумерная проекция аттрактора Лоренца.

Это позволяет проверять способность исследуемых методов воспроизводить как простые, так и сложные геометрические структуры.

### 3. Классический мост Шрёдингера

Рассматривается задача построения наиболее вероятной стохастической эволюции между двумя заданными распределениями.

Для поиска оптимального сопряжения используется **Sinkhorn Optimal Transport**. После получения матрицы сопряжения моделируются траектории частиц между исходным и целевым распределениями.

В экспериментах анализируются:

* траектории частиц;
* эволюция плотности;
* поле дрейфа;
* стоимость транспорта;
* энтропийные характеристики процесса.

### 4. Диффузионная модель VE-SDE

Реализуется диффузионная модель с **Variance Exploding SDE**.

В процессе обучения нейронная сеть `ScoreNet` учится аппроксимировать score-функцию распределения. После обучения выполняется генерация новых объектов посредством обратного процесса.

Для анализа отображаются:

* кривая функции потерь;
* изменение распределения во времени;
* целевое распределение;
* сгенерированные точки;
* траектории обратного диффузионного процесса.

В качестве одного из основных экспериментов используется переход к распределению `mixture_8`.

### 5. Нейронный мост и Flow Matching

В следующем эксперименте классический мост заменяется нейронной моделью.

`BridgeDriftNet` обучается предсказывать поле скоростей, необходимое для перехода между начальным и конечным распределениями. Для обучения используется **Flow Matching**, а оптимальное сопряжение между распределениями формируется с помощью Sinkhorn.

Таким образом, исследуется возможность аппроксимации динамики моста нейронной сетью.

### 6. Исследование параметра ε

Отдельный эксперимент посвящён исследованию параметра `ε`, который определяет уровень стохастичности процесса.

Проводится серия экспериментов для различных значений:

```text
ε = 0.01 ... 6.0
```

Для каждого значения вычисляются различные характеристики процесса, после чего строятся фазовые диаграммы.

Эксперимент позволяет исследовать переход от поведения, близкого к детерминированному Optimal Transport, к более стохастическому режиму. Также реализован интерактивный просмотр изменения траекторий при различных значениях `ε`.

### 7. Анализ динамической системы

Для мостов исследуется поле дрейфа как динамическая система.

Рассматриваются:

* фазовые портреты;
* дивергенция поля скоростей;
* источники и стоки траекторий;
* изменение траекторий во времени;
* показатель Ляпунова.

Дополнительно рассматривается переход от гауссового распределения к распределению, полученному из аттрактора Лоренца.

### 8. Визуализация динамики

Для более наглядного сравнения реализованы анимации движения частиц.

Визуализируются:

* классический мост;
* нейронный мост;
* переход к аттрактору Лоренца.

Также строятся временные ряды физических характеристик, включая энтропию, KL-дивергенцию и производство энтропии.

### 9. Количественное сравнение

В заключительной части выполняется непосредственное сравнение трёх методов:

| Метод                 | Начальное распределение | Конечное распределение | Основной механизм |
| --------------------- | ----------------------- | ---------------------- | ----------------- |
| **VE-SDE**            | шум                     | целевое распределение  | Score Matching    |
| **Классический мост** | `ρ₀`                    | `ρ₁`                   | Sinkhorn + SDE    |
| **Нейронный мост**    | `ρ₀`                    | `ρ₁`                   | Flow Matching     |

Для оценки качества генерации используются несколько метрик:

* **SWD** — Sliced Wasserstein Distance;
* **MMD** — Maximum Mean Discrepancy;
* **KL-divergence**;
* **дифференциальная энтропия**.

Для SWD и MMD дополнительно применяется бутстреп-оценка, позволяющая получить среднее значение метрики и оценку её разброса.
